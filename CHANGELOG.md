# Changelog

All notable changes to this package are documented in this file.
The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),

## [0.1.0] - 2026-11-11

### Added
- First release.
- Language-agnostic code editor for world-space Canvas, driven by a hardware keyboard (Input System).
- Pluggable syntax highlighter and diagnostics, user key bindings (`EditorController.Bind`).
- JIS keyboard layout support, system clipboard integration.
- Bundled JetBrains Mono SemiBold font (SIL OFL 1.1).
